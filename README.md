# Love Reveal ❤️

A romantic static website made for Israt Jaha Mim.

## Files
- index.html
- style.css
- script.js
- music.mp3 (optional)

## Run locally
Open `index.html` in a browser.

## Add music
Put an MP3 file in this folder and uncomment the `<source>` line in `index.html`.

## GitHub Pages
Upload these files to a GitHub repository, then enable:
Settings → Pages → Deploy from branch → main → / (root)
